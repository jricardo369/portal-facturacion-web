# Bienvenida — Servicio de Facturación Electrónica

Pantalla de bienvenida (única entrega) reproducida fielmente desde `2-PantallaBienvenida.png`.

## Requisitos

- Node 18+ y npm
- Angular CLI 16 (`npm i -g @angular/cli` o usar `npx`)

## Instalación y ejecución

```bash
cd portal-facturacion-web
npm install
ng serve
```

Abrir `http://localhost:4200/` (rutas `/` y `/bienvenida`).

## Recurso visual

- `src/assets/2-PantallaBienvenida.png`: referencia original obligatoria del proyecto.
- `src/assets/hero-1.png`, `hero-2.png`, `hero-3.png`: recortes reales de la referencia usados en el hero (no imágenes genéricas).

## Notas

- Solo incluye la pantalla de bienvenida. Sin rutas ni lógica de facturación.
- Responsive móvil / tablet / escritorio, HTML semántico y foco visible.
